# Security

Report a security problem privately through
[GitHub's private vulnerability reporting](https://github.com/Opening-Science/opentwin-synthea/security/advisories/new),
not in a public issue.

Cohort Studio is meant to run on your own computer: it listens on 127.0.0.1
only and has no accounts. Reports about exposing it to a network are welcome,
but running it that way is not supported.

Every record this repository produces is synthetic. If you find what looks
like real personal data in a generated cohort, report it the same way.
